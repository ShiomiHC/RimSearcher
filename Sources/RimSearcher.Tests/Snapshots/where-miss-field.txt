No def in this snapshot has a field path ending in 'noSuchField'. 'rimsearcher fields <DefType> --path-contains <text>' lists the paths that a def type actually has, and 'rimsearcher where --value x' finds which field holds that value.
This says no indexed value sits at that path — not that no such field exists. 'rimsearcher code-search "[\w<>,\[\] ]+ noSuchField;"' finds the declaration, which does say.
